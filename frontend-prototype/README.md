# Plant Aid frontend prototype

A static, frontend-only prototype for the Real-Time Plant Disease Identification System described in `Docs/Software_Requirement_Document.md`.

## Included screens/components

- Responsive Plant Aid dashboard
- Plant photo upload surface
- Live camera scan entry point
- Sample disease classification result with confidence score
- Treatment/care guidance panel
- Recent diagnosis history
- Mobile-responsive layout

This prototype intentionally has no backend/API integration, authentication, camera stream, inference, persistence, or real file upload functionality. Buttons provide prototype feedback only.

Open `index.html` in a browser to review the UI.
